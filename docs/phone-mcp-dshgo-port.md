# 手机操控

前台操控默认使用手机当前屏幕。Android 无障碍服务负责读屏、点击和输入，本机 `phone` MCP 将这些能力提供给 Codex。

## 开启前台操控

1. 在应用的「Android 工具 → 手机操控」打开总开关。
2. 在 Android 无障碍设置中启用 Codex 的手机操控服务。若从旧版本更新，请核对当前服务的开关。
3. 返回桌面并新建对话，让会话加载最新的 MCP 工具。使用 `phone.status` 检查连接、当前模式和任务 ID。

常见流程为 `status` → `screen` → `tap`、`type` 或 `scroll` → `screen` 验证结果 → `finish`。需要用户接手时调用 `handoff`。输入前使用当前屏幕的元素编号，结束时使用当前任务 ID。

## 确认与后台屏

应用名单、敏感元素和用户确认由 Android 端处理。操控中的圆角光效通过无障碍覆盖层显示，暂停、接管、停止和结束时隐藏。熄屏或服务退出会中止任务。未显式结束的任务由空闲超时回收。

后台虚拟屏是可选功能，需要用户在手机操控设置中主动启用并授权对应通道。Root 会检查 UID 和协议，并探测显示与输入。当前真机验证只确认前台服务连接和工具发现，后台兼容性需按 ROM 另行验证。 [设备权限](device-command-policy.md) · [实机范围](compatibility.md)

## 控制悬浮条

在「Android 工具 → 手机操控」可以设置「闲置时将控制悬浮条收成小球」。此设置默认开启，点击小球即可展开控制条。实时活动通知也提供暂停、继续和停止按钮。

## 工具发现与来源

桌面启动时通过 app-server 注册 `mcp_servers.phone`，并部署对应技能。桌面内的 relay 使用来宾 Python。更新后旧对话可能保留旧的工具快照，一加 13 上用新会话确认过 `phone` MCP 的 15 个工具可被发现。

模块移植自 dsh-Go，包含其原生读屏、操作策略和任务控制。 [上游版本](../third-party/dsh-go-phone/UPSTREAM.json) · [第三方声明](../third-party/dsh-go-phone/THIRD_PARTY_NOTICES.md)

## 2026-11-14 源码升级

原生驱动已同步至 dsh-Go `c8cd16dc656bdfeae6a4e47ddb12ad51cb2a180f`，包括焦点输入、视觉观察、原生任务归属和桥接更新。Codex 的启动生命周期、Python relay 和设备工具入口保留。DSH 的 Flutter 界面、引擎启动器、技能发布和开机通道恢复不属于本次移植。

工作中通过 Android Live Updates 请求系统流体云展示手机状态，摘要按 OPPO 模板的五字符空间滚动更新，完整文字保留在展开通知中。通知中的停止按钮绑定创建通知时的任务 ID。暂停、恢复、结束及超时仍由原生任务状态控制，锁屏使用隐藏具体内容的公共通知版本。设置页提供系统「实时活动」入口。

Codex 自有的 `status` 和 `finish` 在操控任务队列之外处理，避免查询占用未释放的任务计数。
带调用方归属的结束请求必须匹配原会话与运行；原生通知的停止按钮仍由用户操作并绑定任务 ID。

这些更新尚未通过新版 APK 的实机验收；既有的 15 工具发现记录属于旧版基线。

原生操控源码与回归测试更新到 dsh-Go `6807372da499979181805b5de48f1d8a5052a8db`，包含三档确认卡（允许一次／本轮允许／取消）、停止后下一轮恢复、免确认判定修复、系统选择器确认修复、可拖动贴边悬浮条和闲置半隐藏小球，以及后台屏实际应用身份、跨应用手势回执和通道探测修复。后台屏协议与配套服务一并升级为 `dsh-vdisplay-4`。

Codex 的原生设置、启动与退出生命周期、MCP 使用范围说明、设备命令白名单及现有圆角边缘光效继续保留。上游独立诊断工具及自动诊断发布依赖 DSH 宿主，未移植；日志仍通过「Android 工具 → 导出日志」获取。前后端版本和 Debian 环境不随本次操控更新改变。
